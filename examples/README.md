# Plantillas KayTopo v0.1.2-alpha

Estas plantillas son ejemplos de entrada. Sustituye los valores por tus datos reales y revisa siempre CRS, datum/marco, zona, hemisferio y, para TME, el meridiano central.

Convención recomendada:

- ID: identificador del punto.
- X: Este o longitud.
- Y: Norte o latitud.
- Z: elevación opcional.

Reglas:

- Usa punto decimal.
- No uses separadores de miles.
- Los metadatos comienzan con `# CLAVE=VALOR`.
- Si omites metadatos, KayTopo puede sugerir una interpretación, pero debes confirmar el sistema en la interfaz.
- Para UTM, especifica zona y hemisferio.
- Para TME, el meridiano central es obligatorio.
- KML/KMZ no necesitan estas plantillas.
